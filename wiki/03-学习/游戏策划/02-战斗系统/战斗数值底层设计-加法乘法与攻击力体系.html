战斗数值底层设计：加法乘法的本质差异、独立乘区与攻击力体系

来源：植光的游文屋（一/二/三/四）
作者：植光
日期：2026-06-26 ~ 2026-07-10
标签：#战斗数值 #伤害公式 #独立乘区 #攻击力 #增伤 #命中率

核心观点

战斗属性的叠加方式归根结底只有两种：加法和乘法。加法定位于高频投放的基础属性（稳定可控但后期稀释），乘法定位于低频投放的稀缺属性（互相放大但容易膨胀）。划分独立乘区的标准是机制独立、词条供给独立、数量均衡。攻击力作为伤害链路的输入端，决定所有后续乘区的基数——前期优先堆攻击力，是因为同等投入下攻击力对总伤害的拉动比例远高于暴击和增伤。

第一篇：加法与乘法的本质差异

数学定义

类型 公式 含义
加法叠加 Final = Base × (1 + Σb_i) 多个加成先求和，再作用于基础值
乘法叠加 Final = Base × Π(1 + b_i) 多个加成各自独立作用于上一步结果

10条词条叠加的巨大差异

假设基础值 1000，10 条 +20% 词条：

  • 加法：1000 × (1 + 200%) = 3000 → ×3
  • 乘法：1000 × 1.2¹⁰ ≈ 6200 → ×6.2

边际效益对比

加法叠加 乘法叠加
绝对提升 恒定（Base×20%=200） 递增（基数越来越大）
相对提升 递减（分母变大→稀释） 恒定（始终×1.2）
现象 稀释 膨胀

怎么选？

加法叠加：稳但后期没感觉

  • ✅ 数值整体稳定、可控，线性外推预测后期总盘容易
  • ✅ 后期不膨胀，版本迭代调参风险小
  • ❌ 相对收益递减：同样+20%，前期从100%→120%体感明显，后期已有200%加成时从300%→320%感觉不到提升
  • 适用：投放密度高、玩家易大量获取的基础属性（攻击力百分比、常规增伤、暴击率）
  • 案例：《艾尔登法环》属性补正——力/敏/智/信/感以加算形式作用于武器基础攻击力，受软上限约束（40/60级）→ 超过阈值后边际递减

乘法叠加：爽但容易失控

  • ✅ 稀缺词条不会被其他乘区稀释，反而能互相放大
  • ❌ 投放太多→后期数值膨胀极快，必须严格限制获取渠道和数量上限
  • 适用：投放密度极低、玩家难以大量获取的稀缺属性（最终伤害加成、对BOSS伤害、特殊机制加成）
  • 案例：《崩坏：星穹铁道》击破流——击破特攻是一个独立于直伤体系（攻击力/暴击/增伤）的独立乘区，击破特攻从0%堆到100% → 击破伤害直接翻倍。正因和直伤分得开，才能做出独立的击破流 build

关键细节：行业内说的「乘法叠加」本质上是多独立乘区结构——同区加算、区间乘算。每个词条各自作为独立乘区时，互相之间按乘法生效。

第二篇：独立乘区与伤害公式通用框架

什么是独立乘区

核心原则：同区加算，异区乘算。 把同类型的加成项打包成一个区间，区间内部用加法，区间之间用乘法。

ATK区输出的是绝对值（带单位），后续每个乘区输出的是无量纲的比例系数。前者是造数，后者是缩放。

怎么划乘区：三个标准

1. 机制独立

不同乘区对应不同的伤害形成机制：基础攻击决定伤害基数、防御/抗性是目标端减伤修正、暴击是概率性爆发放大。只有机制独立的项才适合拆分为独立乘区。

2. 词条供给独立

每个乘区的词条来源应足够分散：攻击主要来自武器与基础成长、增伤来自技能与装备专属部位、暴击来自饰品副词条、最终伤害来自稀有buff——各管各的。

可以允许小幅度交叉（同一件装备同时给ATK%和暴击率没问题），但如果一把武器同时加50%ATK+50%增伤+50%暴击 → 配装意义被抹杀，养成路径高度单一。

3. 数量均衡

  • 乘区过多 → 乘法叠加导致数值膨胀，平衡难度陡增；玩家理解成本高
  • 乘区过少 → 所有加成集中加算，边际递减严重，没有「水桶效应」，策略性不足

所谓水桶效应：总伤害上限由数值最低的乘区决定。单一乘区堆再高、其他乘区过低 → 严重拖累总伤害；只有均衡提升所有乘区，总伤害才最大化。乘区太少，玩家就没得选了。

具体数量根据项目定位灵活确定。放置类/休闲类可极简（如《无尽冬日》远征下仅攻/防/杀伤/生命四个属性），重度ARPG可做更丰富体系。

伤害公式通用框架

链路顺序：先攻后守

暴击区放在增伤区之后、防御区之前——遵循先攻后守逻辑：

  • 攻击端：攻击力造数 → 技能倍率 → 增伤加成 → 暴击放大
  • 防御端：防御减伤 → 抗性减伤 → 最终伤害区

链路中引入固定值加算（如额外造成100点伤害）时，放在防御区前还是后效果天差地别：防御前会被减伤削减（100→50），防御后全额生效（100=100）。必须固化顺序。

等级差惩罚：原神的巧妙设计

防御减伤底层模板：减伤 = DEF / (DEF + K×Level + C)

关键问题：Level填谁的等级？

做法 效果
Level=攻击方（原神做法） 攻击方等级同时出现在分子和分母 = 隐性防御穿透。攻击方等级越高→等效穿透越多→实际减伤越低
Level=防守方 分子分母对消，永远是50%，不论几级打几级。要等级惩罚必须额外加独立乘区

原神设计的高明之处：把等级差惩罚嵌入防御公式本身，不用额外加乘区。但代价是灵活度不高——防御减伤强弱和等级差影响幅度绑定在一起，改K和C会同步变化，没法单独调其中之一。

第三篇：攻击力（ATK）体系详解

攻击力的核心地位

攻击力位于伤害链路的最前端，构成基础伤害。后续增伤、暴击、防御等所有乘区均叠乘于基础伤害之上——攻击力提升会等比例放大后续所有乘区的生效效果。

这也是为什么游戏前期几乎所有养成系统都大量投放攻击力：前期暴击/增伤可获取数值很少，投入产出比远低于攻击力。前期优先堆攻击力，伤害提升见效最快。

艾尔登法环的攻击力计算

实例：同一角色（力气55、灵巧60），同为+10强化 —— 猎犬长牙 806 vs 义手刀 594，差距超过35%。

差距来源两层叠加：

  • 第一层：猎犬长牙基础面板 345 > 义手刀 286。基础值又是补正的乘数——基数越大，同样补正系数算出的绝对值越大
  • 第二层：猎犬长牙力气C+灵巧B > 义手刀力气E+灵巧B，从力气属性获得的补正收益明显更高

三种攻击力加成类型

类型 定义 运算方式
基础攻击力 (Base ATK) 攻击乘区的底层基准，所有ATK%的计算基数 角色等级/职业/武器提供
百分比加成 (ATK%) 以百分比提升攻击力 多个ATK%先加算求和 × Base ATK。同池加算会稀释
固定值加成 (Flat ATK) 以固定数值提升攻击力 取决于公式：可能与ATK%乘算结果加算（不被放大），或与Base一起进入乘算（被放大）

一个重要区分：ATK%放大的是攻击力本身（改输入），技能倍率130%放大的是这一次伤害结果（改输出）。 王者荣耀没有ATK%，只有Flat和技能倍率。

攻击力与其他维度的关系

关系 公式 要点
攻击力 × 攻速 DPS = 单次伤害 × 攻速 高攻低速→爆发秒伤；低攻高速→持续输出。注意：攻速往往只影响普攻，大多数主动技能不受攻速影响
攻击力 × 暴击 期望伤害 = 攻击力 × (1+暴击率×暴伤) 攻击力基数越低时，堆暴击的绝对收益越受限
攻击力 × 增伤 最终伤害 = 最终攻击力 × 攻击系数 × (1+Σ增伤) 两者分属不同乘区，乘算。同等幅度加成词条，在两边基础倍率一致时放哪边总收益相同；但哪边已有越多，新增同幅度词条放到另一边的相对收益越高——这就是水桶效应的实际应用

可迁移思路

  1. 加法先立、乘法后补。 立项初期用加法搭建稳定的数值骨架（易预测、易调试），核心玩法验证通过后再引入少量乘区增加策略深度和后期养成空间。反过来先铺乘区→调试地狱。

  2. 乘区划分的三条硬标准不只是理论。 如果发现某个装备同时大量提供多个乘区的加成 → 那是设计事故。词条供给独立性决定了配装的策略深度——各部位管不同的事，玩家才有选择空间。

  3. 攻击力是玩家最直观的「变强感」。 前期大量投放攻击力不是数值失误，而是刻意为之——让玩家在前2-3小时的每一次升级/换装都感受到伤害数字的明显增长。暴击和增伤是中期才开始发力的维度。

  4. ATK%和技能倍率不是一回事。 前者改的是面板数值（输入），后者改的是伤害结果（输出）。如果设计时把这两者混用，就会导致一些词条的实际效果被误判。

  5. 原神的等级差惩罚设计是教科书式的技巧。 通过让攻击方等级同时出现在防御公式的分子和分母，隐性地把「等级=防御穿透」嵌入了单一公式——不需要额外加乘区。代价是灵活度低，但胜在简洁优雅。

第四篇：命中率与各类增伤详解

命中率（HIT Rate）

命中是攻击方确保攻击生效的概率属性，常与闪避（EVA）构成攻防对偶。命中判定失败 → MISS，随攻击附着的 DOT/debuff 同步失效，相当于这次出手完全无效。

三种常见结算公式

公式类型 规则 特点 代表游戏
减法公式 HIT - EVA 简单直观，国内MMO/放置卡牌最常用 多数国产网游
除法公式 HIT / (HIT + EVA) 天然收敛，不会绝对必中/必不中，但收益感知不够直观。常设5%-95%硬限 少女前线、流放之路
分层判定 按固定优先级依次骰子判定（失误→闪避→招架→格挡） 拆分多条平行养成线，战斗随机层次丰富，但理解成本最高、平衡调试最难 魔兽世界

注意事项：FPS 中的命中通常指武器精度/弹道散布，是手感属性而非概率判定——精度拉满但瞄歪了照样打空。

分层判定模型详解

判定层 作用 攻方堆命中能解决吗？
自身失误 攻击者判定是否失误落空 ✅ 降低失误概率
目标闪避 目标主动躲避 ❌ 无法直接抵消
目标招架 目标武器格挡 ❌ 无法直接抵消
目标格挡 目标盾牌格挡 ❌ 无法直接抵消

增伤体系：伤害实例的标签匹配

核心概念：伤害实例

每一次独立跳出的伤害数字 = 一个伤害实例。普攻命中、技能爆炸、持续伤害跳字互不影响。系统给每个伤害实例打上专属标签：属性类型、攻击/技能类型、触发条件（目标为BOSS/目标血量低于50%）。最终严格按标签匹配判定能吃到哪些增伤。

增伤乘区统一公式（以原神/崩铁为代表）

所有增伤类词条同区加算 → 全部存在边际收益递减。

已有+100%增伤时，再获+20%全局增伤 → 实际相对提升 = 2.2÷2-1 = 10%，不是字面的20%。

增伤类型详解

1. 全局伤害加成

不带任何限定前缀的「造成的伤害提高X%」，覆盖普攻、技能、终结技、追加攻击等绝大多数伤害类型。

2. 属性伤害加成

标签匹配类增伤——只有伤害实例带有对应属性标签时才生效。火伤加成只给火属性伤害，无法增益其他属性。设计目的：引导玩家优先堆叠主输出属性的增伤，让角色输出特征更鲜明。

原神元素反应与属性增伤的关系
反应类型 机制 属性增伤是否生效
增幅反应（蒸发/融化） 给原始直伤乘上固定反应倍率，不产生独立伤害 ✅ 火伤/冰伤/水伤等比例放大最终伤害
激化反应（超激化/蔓激化） 给触发的雷/草直伤额外附加一段激化数值，合并后正常吃属性增伤和暴击 ✅ 雷/草属性增伤生效
剧变反应（超载/超导/感电/绽放） 单独跳出一个独立伤害数字，脱离角色常规攻击面板 ❌ 不吃属性增伤/攻击力/双暴，只吃等级/精通/反应加成/抗性
属性增伤 ≠ 属性穿透/减抗

两者分属不同乘区：

  • 属性增伤：强化自己打出去的伤害（攻方乘区）
  • 属性穿透/减抗：降低目标承受伤害的能力（对方乘区）

3. 持续伤害加成（DoT）

DoT = 在持续时间内按固定节奏反复结算多次。

DoT 结算机制
机制 规则
快照（Snapshot） DoT施加瞬间锁定当时所有面板/Buff，挂上后新增增伤/攻击都不改变已有DoT
实时结算 每跳参考角色当前属性，中途获得Buff立刻提高后续伤害
混合机制 部分数值施加快照，部分每跳重新检查
DoT vs 攻速

攻速通常不直接提高已挂DoT的单跳伤害，也不缩短结算间隔。但如果DoT来源是「攻击命中时概率施加」→ 攻速提升单位时间攻击次数 → 提高施加/刷新/叠层概率。

注意：DoT 不一定吃攻击/属性增伤/双暴/防御，取决于游戏设计。不是所有游戏都让 DoT 走常规伤害体系。

4. BOSS伤害加成

按目标类别触发的条件增伤——检查目标是否带有首领/精英标签。

容易混淆的点 区别
对首领增伤 检查目标的固定类别
对血量<30%敌人增伤 检查目标当前是否满足临时状态
对首领伤害提高 攻击者自身的条件增伤
首领受到伤害提高 施加在首领身上的易伤/承伤提升

根据游戏设计，BOSS_DMG 可定义为独立乘区（最终伤害=常规伤害×(1+ΣBOSS_DMG)），也可归入普通增伤乘区加算。

5. 最终伤害类加成（FINAL_DMG）

在基础伤害、增伤区、暴击区、防御/抗性区全部计算完成后，最后作为独立倍率层参与结算，不和前置乘区的词条产生加算稀释。

案例：《鸣潮》延奏技能

部分角色延奏为下一位登场角色提供特定类型的「伤害加深」：

  • 共鸣解放伤害加深 → 只在效果持续期间使用共鸣解放造成伤害时获得独立倍率
  • 普攻/共鸣解放/不匹配的伤害类型不受强化

配队时不仅要看「伤害加深」百分比，还要看它是否匹配主力角色的主要输出类型和实际输出窗口。 注意鸣潮中多个加深来源之间是加算的。

可迁移思路（第四篇补充）

  1. 命中率公式选减法还是除法，取决于你承不承受得起「绝对必中/必不中」。 减法公式简单但容易出现 100% 命中或 0% 命中的边界情况，除法公式天然收敛但玩家算不清。分层判定模型体验最丰富但调试成本最高——MMO 用分层、二次元卡牌用减法、硬核单机可以考虑除法。

  2. 增伤区的所有词条同区加算——这个设计选择比你想的重要。 同区加算 → 玩家堆再多不同类型的增伤都会有边际递减，这迫使玩家追求「水桶式均衡」而不是单维度拉满。如果想鼓励某种极端 build，把它单独拉出来做独立乘区。

  3. DoT 的快照 vs 实时结算，影响的是战斗节奏。 快照机制鼓励「爆发窗口期全力上 DoT」，实时机制鼓励「持续保持 Buff 覆盖」。选哪个取决于你的战斗设计是偏回合型爆发还是偏持续拉扯。

  4. 属性增伤和元素反应的关系要提前设计清楚，不然后面全是坑。 原神的三类反应对属性增伤的不同处理（增幅能吃、激化能吃附加部分、剧变完全不吃）——这种差异化不是 BUG，是有意为之的设计分层。但如果没有提前规划，玩家发现「明明写了火伤加成结果这个反应不吃」就是事故。
