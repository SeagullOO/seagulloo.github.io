敌人组合设计：先看关系再看数值的战斗压力法则

来源：欧米De游戏开发小屋
作者：欧米
日期：2026-06-23
标签：#战斗设计 #敌人设计 #组合设计 #游戏设计

核心观点

单个敌人的血量伤害容易调，但真正决定战斗体验的是敌人之间的关系。 好的组合不是把高压敌人堆在一起，而是让每个敌人有不同职责（主威胁/远程干扰/近身逼迫/资源提供），形成玩家能读懂的压力层次。设计敌人组合不是为了更虐，而是为了让玩家不断做出有意义的优先级判断。

为什么组合比单个敌人更重要

  • 单个敌人好分析：血量、伤害、前后摇、范围、移速、霸体，都是可调参数，玩家打几次就能摸清
  • 但玩家进入关卡时，面对的是敌群 + 地形 + 距离 + 资源 + 任务目标的复合体
  • 战斗压力来源：伤害、站位、视野、控制、资源消耗、时间限制——单个敌人只给一种，组合把几种压力叠在一起
  • 组合的关键问题：玩家要不断判断”先打谁”

经典案例分析

《DOOM Eternal》：小怪是资源点

敌人角色 机制
小僵尸/士兵 Glory Kill 补血 / Chainsaw 补弹药 / Flame Belch 补甲
Arachnotron 炮台远程持续压制
Mancubus 大范围火力限制走位
Whiplash 快速贴地切入，从视野边缘进场

核心：小怪单独看威胁为零，但在战斗中它们是资源补给站——玩家不能只盯着精英打，要留着几个小怪在关键时刻用。

《生化危机4 重制版》村庄战：远近搭配改变空间

  • 近战村民逼玩家移动（不能站桩），远程投掷惩罚站位
  • 链锯男不是跑得快，而是”被追上就危险”——逼迫玩家提前让位
  • 房屋/窗户/楼梯/屋顶成了战斗的一部分，空间被敌人挤紧
  • 敌人没有变聪明，是组合让空间变小了

《Left 4 Dead 2》：组合破坏队形

感染者 作用
Boomer 遮挡视野 + 引来尸潮
Smoker 拖走一个玩家，破坏阵型
Hunter 扑倒落单目标
Charger 撞散队伍
普通尸潮 数量压力，堵塞救援路线

核心：很多死亡不是因为某个感染者数值太高，而是队形被拆开→视野被遮→救援路线被堵→局面一步步失控。

《XCOM 2》：回合制也有组合压力

  • 普通士兵 → 基础射击压力
  • 军官 → 标记目标，让后续伤害变高
  • Stun Lancer → 高速近身，惩罚拖延
  • Sectoid → 心灵控制/复活尸体
  • 回合制把压力从”反应速度”转移到**”行动顺序”和”风险管理”**上

《光环》Covenant：经典分工模版

敌人 角色
Grunt 数量压力、场面噪音
Jackal（持盾） 挡正面射击，逼玩家侧向移动
Elite 核心威胁，护盾强、灵活

核心：玩家能读懂——先清 Grunt 降噪音 → 绕开盾兵 → 集中火力破 Elite。不是一团混沌，而是有层次。

反面案例：神皮双人组

  • 单个敌人都有清晰节奏，但同时在场后安全窗口被压得很窄
  • 问题不在难度，而在玩家很难判断自己哪里做错了
  • 多个敌人同时做同一种高压行为（都突进/都远程压制/都控制）→ 战斗变成噪音

组合设计原则

开工前的检查清单

问题 目的
谁是主要威胁？ 给玩家一个明确的优先目标
谁会迫使玩家移动？ 制造空间压力
谁会限制玩家移动？ 制造距离/方向约束
谁会打断玩家常用打法？ 打破惯性
谁可以被快速清掉？ 给玩家缓冲突破口

两个公式

  1. 主压力 + 次压力：远程压制 + 近战逼近；高血盾兵 + 需优先处理的后排；快速突进 + 低威胁杂兵
  2. 不要全员高压：如果所有单位都”很重要”，玩家找不到突破口；如果只有血量差异，组合会单调

和地形一起看

同样是 2 远程 + 3 近战，放在走廊 / 广场 / 二层平台 / 转角房间——体验完全不同。很多时候变难不是敌人变强，是空间变小了。

可迁移思路

  1. 先排关系，再调数值：明确敌人之间的职责分工后，再去调血量伤害出现时机——反过来做容易做成一团混乱
  2. 给每个敌人一个会”改变玩家决策”的机制，而不是仅仅数值不同
  3. 小怪可以是资源/节奏点：DOOM Eternal 的 Glory Kill 思路——让低威胁敌人承载资源补给功能，迫使玩家主动保留它们
  4. 组合要有空隙：不是安全区域，而是清晰的攻击窗口、可先杀的突破口、可绕开的障碍——只要玩家还能找到处理顺序，就不会烦躁
  5. 测试不要在空白场地测：带地形、资源点、任务目标一起测，压力是否清楚、玩家是否能读懂局面
