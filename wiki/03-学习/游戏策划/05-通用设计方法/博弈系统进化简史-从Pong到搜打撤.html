博弈系统进化简史：从Pong到搜打撤的博弈论应用之路

来源：GAMEOFFER
作者：GAMEOFFER
日期：2026-07-08
标签：#博弈论 #游戏设计理论 #零和博弈 #纳什均衡 #多维博弈

核心观点

格斗、射击、RPG、跑图解谜——所有游戏带给玩家的乐趣，都源自同一个底层系统：博弈。 从 1972 年《Pong》的对称零和博弈，到《街霸2》引入混合策略纳什均衡，到现代 RPG 的非零和博弈（状态损耗 → 决策取舍），再到搜打撤的多维博弈融合——博弈系统的复杂度随商业模式的演进（街机按次收费 → 买断制 → 持续运营）而不断升级。设计博弈系统的关键是：选对主博弈类型匹配你的游戏类型，然后确保「高风险 = 高回报」——否则玩家会自己找到最轻松的解法（如全员蹲坑），毁掉整个博弈生态。

第一阶段：零和博弈——电子游戏的起点

《Pong》（1972）：对称零和博弈

  • 两个玩家拥有完全对等的条件和信息
  • 博弈核心：比「谁的操作更快」
  • 确立了电子游戏博弈的最底层形式

从双人到单人：不完全信息博弈的诞生

街机单人模式（1973）：电脑预封装 AI 行动路径来模拟对手。从此：

  • PvE 游戏：玩家一开始不知道敌人分布、地图设计、资源分布
  • 电脑敌人时刻掌握玩家位置
  • 玩家在反复死亡中获得经验 → 将不完全信息转化为完全信息
  • 完成这个过程 → 大脑 VTA 分泌多巴胺 → 「我比预期做得更好」的满足感

案例：《魂斗罗》——玩家像《明日边缘》一样在反复死亡中学习，逆转信息不对等，利用规则获胜。

第二阶段：纳什均衡——从「比手速」到「比心理」

《街头霸王2》（1991）：投技的引入

投技让格斗从「谁出拳更快」变成剪刀石头布：

在这个矩阵中不存在「必胜策略」。玩家必须在战斗中不断变换起手模式，防止被对手抓住习惯反制——这就是混合策略纳什均衡。

它通过「零和博弈 + 纳什均衡」的混合模式，将 PvP 博弈从「比手速」「比操作」提升到「比心理素质」的层面。让双方不断寻找对方策略的「非随机性」并加以利用，通过「以小博大」的心理快感鼓励玩家探索新打法。

第三阶段：非零和博弈——状态损耗与决策取舍

什么是非零和博弈

代指所有「双方收益总和不为 0」的博弈——可以双赢，也可以双输。

PvE 中的非零和博弈

现代 RPG 的常见设计：战斗受伤 → 生命值不会在胜利后自动恢复 → 玩家要么顶着不全状态继续战斗，要么付出代价回复。这代价可以是：

  • 购买的道具
  • 消耗魔法值的技能
  • 更危险的路线
  • 强制跑图回血点（如《崩坏：星穹铁道》靠传送点回血 = 以多跑几步图为代价换取完全状态）

PvP 中的非零和博弈

《CS:GO》对枪场景——在信息对等情况下，六种可能结果呈高尔顿钉板模型（中间高、两边低的钟形曲线）：

  1. A 颗秒 B
  2. 双方换血，都没死
  3. A 击杀 B 但被击中（损失血量）
  4. B 击杀 A 但被击中
  5. 双方互换
  6. B 颗秒 A

保证自身状态完整且拿到战果的概率非常小，大概率出现「双输」局面。这种设计迫使玩家在「冒险突进」和「保守推进」间做出取舍，根据经验评估决策的期望收益是否值得承担潜在风险。

为什么非零和博弈在买断制时代爆发？

街机商业模式：「让玩家快速死 → 投更多币」→ 死亡是不愉快的惩罚。
个人电脑/主机买断制：「让玩家觉得物有所值」→ 设计师可以创造更广阔的世界、更深度的系统和更复杂的互动。状态损耗机制在街机时代是无法想象的——每死一次亏一次钱。

第四阶段：多维博弈——搜打撤的博弈融合

案例：《三角洲行动》

一局游戏中同时运行多种博弈类型：

层级 博弈类型 体现
遭遇战 不完全信息博弈 多队互相不知道对方人数、配置、位置 → 必须靠技能道具收集信息
多队对峙 非零和博弈（负和） 任何造成自身损失的战斗都是双输——战损过大 → 被第三方收掉
时间限制 迫使破局 三方之一必须主动出击——否则所有人耗到时间结束
整局结果 零和博弈 赢家通吃，输家失去一切
局间决策 重复博弈（沉没成本） 选哪个地图、用什么打法、起什么装备

多维博弈相互融合，最终呈现出流水百万的现象级产品。

实用方法论：怎么给每种游戏选对博弈系统？

反向推导法：看外挂用什么挂

外挂的本质是让玩家跳过博弈过程直接获得结果。反推：外挂泛滥在哪个环节 → 那个环节的博弈是游戏的核心博弈类型。

  • FPS 枪战外挂（自瞄/透视）→ 核心博弈是信息+反应速度
  • MMO 脚本挂（自动打金/练级）→ 核心博弈是资源获取效率
  • 策略游戏外挂（全图视野）→ 核心博弈是不完全信息下的决策

「高风险 = 高回报」是铁律

博弈的乐趣在于「以小博大」——高风险决策必须对应高回报，低风险决策必须对应低回报。

违反这个规则的后果：「老六」「龟仙人」「蹲比」现象。

人天然倾向更轻松、更方便、收益又高的方法。如果蹲在别人必经之路上等一梭子比主动推进的收益还高——那所有人都会蹲，游戏变成十二把狙往草丛一趴，半小时对局前二十五分钟听不见枪声。这不是玩家的问题，是博弈设计的问题。

博弈系统的进化驱动力：商业模式

时代 商业模式 博弈设计
街机时代 按次收费（投币） 快速消耗生命数 → 诱导投币 → 零和博弈为主
买断制时代 一次性付费 让玩家觉得物有所值 → 非零和博弈、开放世界、深层系统
持续运营时代 免费+内购/通行证 多维博弈融合 → 既要零和的刺激感（吸引竞技玩家），又要非零和的容错空间（留住休闲玩家）

可迁移思路

  1. 别迷信「博弈越复杂越好」。 多维博弈适合搜打撤这种本身就多层的游戏类型，但给一个休闲消除游戏叠上不完全信息+非零和+重复博弈就是灾难。博弈复杂度要匹配产品定位。

  2. 排查你的游戏里有没有「最优无聊策略」。 如果玩家发现蹲坑/挂机/重复低操作行为能获得与高风险高操作行为相同甚至更高的收益 → 那是博弈设计缺陷。立刻调整风险-回报曲线。

  3. 反推外挂可以验证博弈设计是否合理。 如果一个博弈环节被外挂大量跳过（如自动瞄准替代了手动瞄准博弈），说明这个博弈环节对多数玩家来说是负担而非乐趣。考虑：降低该环节的难度？提供辅助机制（如辅助瞄准）？还是直接用其他博弈替代？

  4. 非零和博弈是留存的关键。 纯粹的零和博弈（赢家通吃、输家全输）让 50% 的玩家每局都以挫败结束。状态损耗、跑图代价、分段奖励——这些非零和设计让输家也能「带点什么走」，降低退出概率。
